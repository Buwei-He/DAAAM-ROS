# DAAAM ROS — ROS 2 Interface for DAAAM

ROS 2 wrapper for [DAAAM](https://github.com/MIT-SPARK/DAAAM). Handles ROS 2 I/O, topic publishing, and integration with [Hydra](https://github.com/MIT-SPARK/Hydra) for 3D Dynamic Scene Graph construction.

## Installation & Running

See the [DAAAM repository](https://github.com/MIT-SPARK/DAAAM):
- **[Installation](https://github.com/MIT-SPARK/DAAAM/blob/main/INSTALL.md)** — the install script clones this package automatically.
- **[Running](https://github.com/MIT-SPARK/DAAAM/blob/main/RUNNING.md)** — dataset download, bag creation, pipeline launch, post-processing.
